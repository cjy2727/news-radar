# News Radar · Windows 배포

## 다운로드와 실행

아래 **Assets**에서 **NewsRadar.exe**를 다운로드하고 더블클릭하세요.
설치 마법사 없이 실행됩니다. Python·Docker·API 키는 필요 없습니다.
`Source code` 파일은 일반 사용자가 받을 필요가 없습니다.

Windows 10/11 64비트용입니다. 인터넷 연결이 필요합니다.

## 포함 기능

- 삼성전자·하이닉스 기본 키워드와 키워드 추가·삭제
- Google·네이버·다음 관련 기사 수집, 검색·필터
- 30분 자동 수집과 수동 수집
- 브라우저 자동 열기, 중복 실행 방지, 종료 버튼
- 사용자 폴더에 기사·설정 보관

## 업데이트

기존 실행 창에서 종료한 뒤 EXE 파일만 교체하세요. 데이터는 `%LOCALAPPDATA%\NewsRadar`에 유지됩니다.

서명되지 않은 실행 파일이므로 보안 경고가 표시될 수 있습니다. 회사 PC는 담당자에게 확인하세요.
네이버 직접 수집 기사는 날짜 미제공으로 표시되며, 검색 사이트 구조 변경이나 접근 제한에 따라 수집이 실패할 수 있습니다.
