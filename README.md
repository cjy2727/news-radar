# News Radar · Windows 뉴스 레이더

**NewsRadar.exe 하나만 더블클릭**하면 뉴스 페이지가 열립니다. 사용자는 Python, Docker, API 키를 설치하거나 설정할 필요가 없습니다.

## 시작하기

이 저장소는 소스 코드와 사용 설명서를 제공합니다. 소스 실행과 Windows 실행 파일 빌드 방법은 아래 **개발자 실행·빌드**를 참고하세요.

**Windows 10/11 64비트 PC**에서 사용합니다. 설치 마법사 없이 파일 하나로 실행하는 프로그램입니다. Mac·스마트폰용 프로그램이 아닙니다.

## 실행 방법

1. 배포받은 `NewsRadar.exe`를 저장하고 더블클릭합니다.
2. 실행 창과 기본 브라우저의 뉴스 페이지가 열립니다. 첫 실행은 잠시 걸릴 수 있습니다.
3. 키워드를 추가하거나 **지금 수집하기**를 누릅니다. 기본 키워드는 삼성전자·하이닉스이며 30분마다 자동 수집합니다.
4. 종료하려면 실행 창의 **종료** 또는 **X**를 누릅니다. 진행 중인 요청을 마치는 동안 잠시 기다릴 수 있습니다.

브라우저만 닫으면 수집은 계속됩니다. 실행 창에서 **뉴스 페이지 열기**로 다시 열 수 있습니다. EXE를 다시 실행하면 기존 페이지를 엽니다. PC나 프로그램을 종료하면 자동 수집도 멈춥니다. 기사 검색에는 인터넷 연결이 필요합니다.

서버는 이 PC에서만 접속 가능한 `127.0.0.1`에서 실행됩니다. 기본 포트 8080이 사용 중이면 비어 있는 포트를 자동 선택합니다. 실제 주소는 실행 창에 표시됩니다.

## 데이터와 업데이트

- 기사·키워드: `%LOCALAPPDATA%\NewsRadar\news.sqlite3`
- 로그: `%LOCALAPPDATA%\NewsRadar\server.log`
- 실행 창의 **데이터 폴더** 버튼으로 저장 위치를 열 수 있습니다.
- 업데이트: 프로그램 종료 후 EXE만 새 버전으로 교체합니다. 데이터는 유지됩니다.
- 백업: 프로그램 종료 후 데이터 폴더를 복사합니다.
- 기존 소스 버전의 `data/`나 Codespaces 데이터는 자동으로 가져오지 않습니다. 기존 서버를 정상 종료한 뒤 DB를 백업하여 새 저장 위치로 옮길 수 있습니다. 새 데이터가 있다면 먼저 별도 백업하세요.

Windows 10/11 64비트용입니다. 코드 서명이 없어 Windows 또는 보안 제품의 실행 경고가 표시될 수 있습니다. 회사 환경의 배포 승인·코드 서명은 별도입니다.

## 자주 묻는 질문

**브라우저가 안 열려요.** 실행 창의 **뉴스 페이지 열기**를 누르세요. 그래도 열리지 않으면 창에 표시된 `http://127.0.0.1:숫자` 주소를 브라우저 주소창에 입력하세요.

**뉴스가 안 보여요.** 인터넷 연결을 확인하고 **지금 수집하기**를 누른 뒤 기다리세요. 페이지 하단의 **검색 채널 연결 및 수집 상태**에서 오류를 확인할 수 있습니다. 검색 조건과 기간 필터도 확인하세요.

**실행이 차단됐어요.** 파일의 출처와 빌드 과정을 먼저 확인하세요. 보안 프로그램을 끄지 마세요. 회사 PC라면 담당자에게 실행 허용 여부를 문의하세요.

**새 버전은 어떻게 설치하나요?** 실행 창에서 종료한 뒤 최신 소스로 빌드한 EXE로 기존 파일을 교체하세요. 자동 업데이트 기능은 없으며, 저장된 기사와 키워드는 유지됩니다.

**삭제는 어떻게 하나요?** 실행 창에서 종료하고 EXE 파일을 삭제하세요. 저장 데이터는 남습니다. 데이터까지 삭제하려면 필요한 내용을 먼저 백업하고 실행 창의 **데이터 폴더**에서 확인한 폴더를 삭제하세요.

**문제가 계속되면요?** [문제 신고](https://github.com/cjy2727/news-radar/issues)에 오류 화면과 사용 중인 버전을 적어 주세요. 로그는 데이터 폴더의 `server.log`에 있습니다. 개인정보나 인증 정보를 공개하지 마세요.

## 수집 방식

공식 검색 API와 AI API는 사용하지 않습니다.

| 채널 | 방식 |
| --- | --- |
| Google | Google 뉴스 RSS, 최근 7일 |
| Naver | Google RSS의 `site:news.naver.com` 검색을 7일 → 30일 → 기간 제한 없음 순서로 진행. 유효 결과가 없으면 네이버 뉴스 검색 페이지 직접 수집 |
| Daum | Google RSS의 `site:v.daum.net` 검색, 최근 7일 |

제목·요약에 키워드가 포함된 결과만 저장합니다. RSS 요청당 최대 100건, 네이버 직접 수집은 검색 첫 화면을 읽습니다. 직접 수집 기사는 날짜를 확실히 추출하지 못하므로 **날짜 미제공**으로 표시하고 기간 필터에서는 제외합니다. Google 경유 결과는 포털 직접 검색과 다릅니다. 구조 변경·접근 제한·네트워크 오류는 수집 상태에 표시합니다.

키워드는 최대 20개입니다. 제목·언론사 기준 중복 처리를 하지만 표기가 다르면 중복이 남을 수 있습니다. 원문 전문은 저장하지 않습니다. 저장 후 90일이 지난 기사를 정리하고 화면에는 최신 1,000건을 표시합니다.

## 개발자 실행·빌드

> 프로그램을 사용하기만 한다면 아래 작업은 필요 없습니다.

Windows와 Python(Tkinter 포함)이 필요합니다. 일반 사용자에게는 아래 절차가 필요 없습니다.

```powershell
python launcher.py
python -m pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

결과는 **dist/NewsRadar.exe**입니다. 이 파일 하나만 전달합니다. GitHub의 Source code.zip은 실행 파일이 아닙니다. Docker·Compose·Codespaces 설정은 제거했습니다.

자체 검증은 임시 저장소에서 번들 HTML/CSS/JS, HTTP, 포트 충돌, 중복 실행, Tk 창 생성·종료, SQLite 재시작 보존을 검사합니다. 결과는 `build/exe-self-test.json`에 기록합니다. 실제 인터넷 수집이나 별도 새 PC 동작을 대신 검증하지 않습니다.

```powershell
python -m unittest discover -s tests -v
```

### 새 버전 배포

변경 내용을 커밋하고 push한 뒤 새로운 버전 태그를 push합니다.

```powershell
git tag v0.1.1
git push origin main
git push origin v0.1.1
```

GitHub Actions의 **Windows release**가 Windows EXE를 빌드하고 자동 검증을 통과하면 GitHub Releases에 `NewsRadar.exe`와 무결성 확인용 `SHA256SUMS.txt`를 게시합니다. 실패하면 Actions 로그를 확인하세요. 이미 게시된 태그로 다시 실행하면 기존 릴리스와 자산을 변경하지 않고 건너뜁니다. 새 버전은 새 태그를 사용하세요. 배포 내용은 `docs/RELEASE-NOTES.md`에서 관리합니다.
